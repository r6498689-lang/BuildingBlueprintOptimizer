# 建筑蓝图优化器

对已有建筑蓝图进行 **ISM 实例化、Nanite、单项或批量优化**，支持另存副本、备份后替换、备份管理和内存记录。

**版本：2.0.0 · UE 5.6.1 · Windows 编辑器**

## 独立安装

本插件的模块名为 `BuildingBlueprintOptimizer`，不依赖创建插件。它可以单独安装，也可以与 [建筑蓝图批量创建器](https://github.com/r6498689-lang/BuildingBlueprintCreator) 同时安装。这里不提供 Actor 转蓝图或按父级创建功能。

1. 下载仓库源码，将根目录内容放进 `<项目>/Plugins/BuildingBlueprintOptimizer/`，目录下应直接有 `BuildingBlueprintOptimizer.uplugin` 和 `Source`。
2. 使用 UE 5.6.1 的 C++ 编译环境编译 Editor 目标；依赖引擎 Datasmith Content。
3. 在插件管理器启用 **Building Blueprint Optimizer**，重启编辑器。

源码版不包含预编译 DLL、UE 引擎代码或项目素材。升级时替换插件目录，避免保留旧二进制。

## 怎么优化

1. 在内容浏览器中选择一个或多个兼容的建筑蓝图，先编译并保存资产及依赖。
2. 右键选择 **优化建筑蓝图…**。
3. 勾选 **重复模型转为 ISM**、**开启原模型的 Nanite**，至少一项。
4. 选择 **另存副本** 或 **替换原蓝图**；替换前会校验并创建原蓝图备份。
5. 批量另存时选择统一 `/Game` 输出目录，执行后检查成功和失败报告。

只处理兼容的重复叶子零件，不跨建筑或直接父级强行归组；已有 ISM/HISM 保留。优化前后检查模型、材质、变换和节点结构。

## 输入范围

沿用原 1.9.5 的兼容范围，接受创建器生成且以原生 Actor 为父类的建筑蓝图，或具有兼容结构和标记的资产；创建器无需安装或加载。原生 Actor、任意游戏逻辑蓝图、带自定义变量/时间轴/接口或已连接脚本的蓝图不在自动优化范围。

保留 `BuildingBlueprintCreator.GeneratedBuilding` 资产标记是为了识别已有建筑，并非对创建插件模块的依赖。优化后的资产仍以原生 Actor 为父类。

## 保存、备份与内存

- 开启 Nanite 会修改并保存引用的原 Static Mesh，影响所有引用。蓝图备份不包含模型，不能用于回退 Nanite 设置。
- **每个优化成功项随后执行“全部保存”**，包括关卡、外部 Actor 及其他已修改资源。未命名关卡会弹出保存对话框；取消或失败会记为失败，已生成结果保留。
- 新备份和日志位于当前工程 `Saved/BuildingBlueprintOptimizer/`。备份管理支持全选、取消全选，删除仍需确认；不自动删除旧备份。
- 旧合并版的 `Saved/BuildingBlueprintCreator/` 备份保持原样，不自动迁移。恢复前关闭 UE，再按备份记录复制回原路径。
- Nanite 构建保存后，只对单源 LOD、无 HiRes、不在编译、无未保存修改且编辑窗口未打开的模型清理 CPU 描述缓存。保留源数据、渲染/碰撞数据和撤销记录，不保证消除全部内存增长。

## 2.0.0 拆分

从原合并版 1.9.5 提取已有蓝图优化功能，使用独立模块、反射类型和接口。移除创建蓝图菜单、创建接口与按父级创建流程，支持和创建插件共存。
